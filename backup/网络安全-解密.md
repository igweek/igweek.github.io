## 第二题（URL→Base64→Hex）：
```python
import base64, urllib.parse

cipher = "53%2057%2035%206d%2062%2033%204a%2074%2059%2058%2052%2070%2062%2032%2034%2067%2055%2032%2056%206a%2064%2058%204a%2070%2064%2048%206b%2067%2051%2057%2052%2074%2061%2057%2035%2070%2063%2033%2052%2079%2059%2058%2052%2076%2063%2067%203d%203d"

url_res = urllib.parse.unquote(cipher)
hex_res = bytes.fromhex(url_res).decode()
plaintext = base64.b64decode(hex_res).decode()
print(plaintext)
```

## 第八题（URL→ROT13→Base64）：
```python
import base64, urllib.parse, codecs

cipher = "VmFzYmV6bmd2YmElMjBGcnBoZXZnbCUyME5xenZhdmZnZW5nYmU="

b64_res = base64.b64decode(cipher).decode()
rot_res = codecs.encode(b64_res, 'rot_13')
plaintext = urllib.parse.unquote(rot_res)
print(plaintext)
```
